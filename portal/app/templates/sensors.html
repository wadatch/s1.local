ホーム・エリア・ルームの対応づけは config/switchbot.yml で持っている。 SwitchBot API はホームもルームも返さないため、設定側に置くしかない。 エリアの並び順は設定に書いた順。

各ホームの中はエリア順、同じエリアの中は暑い順。「取得」は値を取り込んでからの経過時間で、 これが伸びていれば表示中の温度はもう現在の値ではない。 取得間隔は 10 分（SwitchBot API の 1 日 10,000 回の上限に収めるため）。

この表は 30 秒ごとに自動で更新される。 すぐ見たいときは「更新」ボタン、スマホでは画面を下に引っ張っても更新できる。

API取得 を OFF にすると、そのセンサーへの問い合わせを行わなくなる。 API の消費が減るので、使っていないセンサーは止めておくとよい。 OFF はすぐ反映され、ON に戻したときは次の取得（最大 10 分後）で値が入る。
